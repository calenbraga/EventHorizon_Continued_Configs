# EventHorizon_Continued
EventHorizon_Continued_Configs for The War Within

* Provides a fresh install of EventHorizon_Continued to have empty template files for customization.

* Modify or replace the core_my_config.lua with your own, or suffer my defaults 

* All other files included in the curse distribution of EventHorizon_Configs are placeholders only, so
to customize your class, copy the default EventHorizon_class/config.lua to EventHorizon_Configs/class_my_config.lua and modify.

**Do not reinstall this package from curseforge unless you intend to wipe out any customizations you have made.**
